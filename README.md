Dashboard oficial de imóveis, gerado pela fonte XML VivaReal do site Marcus Béda.

## Link atual

https://dashboard-imoveis-xml.vercel.app

## Fonte oficial

http://www.marcusbeda.com.br/feed/vivareal/yncz3b2guhkliqe9rx684t5fm78037_www.marcusbeda.com.br.xml

## Atualização automática

GitHub Actions agenda a atualização às 06h, 13h e 23h no horário de Goiânia.

## Regra operacional

Se está no XML/feed oficial, está disponível. Se sair do XML, sai do dashboard.
